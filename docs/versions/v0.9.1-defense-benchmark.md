# v0.9.1 答辩冻结评测集

状态：已完成

日期：2026-07-27

## 目标

为论文《跨模态特征融合机制及微调策略研究与应用》的系统测评和现场答辩准备一个
可复现、带真实标注、不会与无标注工程图片混淆的专用集合。

## 固定设计

- 来源：`rsvqa-hr-product-aligned-eval-20260727-1796e90` 的 `provider-dev`。
- 规模：512 条问题、512 张唯一图像。
- 分层：Presence、Count、Area、Comparison 各 128 条。
- 图像：从受控 TIFF 解码为 RGB 后无损编码为 PNG，逐文件记录 SHA-256。
- 问题：保留研究评测中的原始英文问题，不由 LLM 改写。
- 盲测：`questions.csv` 不含答案，`answer-key.csv` 独立保存。
- 展示：固定种子后在每类内按 grouped gold answer 分层轮询取 6 条，共 24 条；
  覆盖 Count 的 0/非零、二分类的 yes/no 和多个 Area 档，不依据模型正确性选样本。

本地数据生成到 `data/defense-benchmark-v1/`，其中含受限图像和逐样本 gold，整个目录
被 Git 忽略。Git 只保存构建脚本、聚合评测脚本与本规范。

## 测评口径

主要报告：

1. OA 与 Wilson 95% CI。
2. 四题型 accuracy、AA 与分层 bootstrap 95% CI。
3. top-5 hit rate。
4. Count 的 zero/nonzero 分层准确率。
5. 正确与错误样本的平均 confidence，仅作诊断，不作为风险保证。

程序只在内存中保存预测，输出聚合 JSON，不落盘逐样本 prediction。答辩集不能替代论文
已核准 full test/test_phili 指标或 3072 条 sealed diagnostic，也不得根据本集合结果调整
模型、canonical normalizer、阈值或 prompt。

## 构建

```bash
services/model-service/.venv/bin/python scripts/build_defense_benchmark.py \
  --evaluation-release evaluation-releases/rsvqa-hr-product-aligned-eval-20260727-1796e90 \
  --model-manifest model-releases/rsvqa-hr-qdrop15-predicted-soft-20260727-9b4ade2/model-release.json
```

## 聚合测评

```bash
docker run --rm --cpus=2 --memory=6g \
  -v "$PWD/data/defense-benchmark-v1:/benchmark:ro" \
  -v "$PWD/model-releases:/opt/rsvqa/model-releases:ro" \
  -v "$PWD/scripts/evaluate_defense_benchmark.py:/tmp/evaluate.py:ro" \
  rs-vqa-model-service:latest \
  python /tmp/evaluate.py \
  --benchmark /benchmark \
  --model-manifest /opt/rsvqa/model-releases/rsvqa-hr-qdrop15-predicted-soft-20260727-9b4ade2/model-release.json
```

只评测 24 条现场展示子集时追加 `--showcase`。完整 512 条结果才适合报告该答辩集的聚合能力。
