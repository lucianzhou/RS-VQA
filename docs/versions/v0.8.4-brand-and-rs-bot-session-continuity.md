# v0.8.4 品牌标识与 RS-Bot 会话连续性

## 版本目标

本版本解决两个直接影响产品辨识度与连续使用体验的问题：

1. 用 RS-VQA 专属品牌标识替换通用的 `RS` 文字方块和缺失的浏览器图标。
2. 让工作台内的 RS-Bot 按当前 VQA 对话恢复最近一次持久会话，关闭抽屉不再隐式丢失上下文。

## 品牌标识

新标识延续 Mineral Forest 视觉体系，由三种语义组成：

- 四角取景框：遥感影像与受控分析范围；
- 中部地表轨迹：地表空间信息；
- 赭金色节点：视觉问答中的问题定位与结果节点。

标识同时用于侧栏、系统启动状态和浏览器标签页，在 16–32 px 小尺寸下仍保持轮廓清晰。页面结构、字体和既有配色未被重新设计。

## RS-Bot 会话连续性

### 默认行为

- 打开某个 VQA 对话的 RS-Bot 时，系统查询该对话最近更新且未归档的 Bot 会话。
- 关闭 RS-Bot 只隐藏抽屉，不清空或新建会话。
- 在项目或对话之间切换时，每个 VQA 对话恢复自己的最近 Bot 历史。
- 对话第一次向 RS-Bot 提问时才创建持久会话，并且一次提问只创建一个会话。
- 刚完成但尚在刷新后端历史的回答会暂存在统一 Hook 中，刷新后按 `runId` 去重。

### 显式新建

抽屉标题栏新增“新建 RS-Bot 对话”图标。只有用户主动点击该图标时，当前 VQA 对话才切换到一个新的空白 Bot 会话；关闭按钮不承担清空语义。

### 复用边界

上下文解析、会话创建、恢复、流式运行和临时结果去重全部集中在 `src/rsbot.ts`。工作台抽屉与独立 RS-Bot 页面继续复用同一会话运行层，后续新增项目级或批量任务级 Bot 入口时无需复制状态逻辑。

## 验收结果

- 前端单元与组件测试：40 项通过。
- 会话专项覆盖：
  - 从会话列表选择当前上下文的最近会话；
  - VQA 对话 A → B → A 后恢复 A 的历史；
  - 首次提问仅创建一个持久会话。
- TypeScript 类型检查通过。
- Vite 生产构建通过。

## 不变边界

- 未修改研究模型、checkpoint、推理协议或模型发布物。
- 未修改 Gemini、Qwen 或 RS-VQA Provider 配置。
- 未改变外部模型与研究模型的身份展示边界。
