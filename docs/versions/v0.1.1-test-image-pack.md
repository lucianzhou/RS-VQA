## 1. 本版目标

为 v0.1.0 MVP 提供一个本地、可重复下载、可追溯的工程测试影像库，服务于：

- 单张图像上传与 VQA 主路径演示；
- 图像格式、大小、预处理和接口 smoke 测试；
- 后续“流程化批量 VQA”功能的批量输入、失败处理和吞吐验证。

本版不构造模型评测数据集，不创建人工问答标注，也不改变研究模型、训练代码或论文实验结果。

## 2. 功能与目录结构

```text
data/test-images/
├── README.md             # 数据来源、用途和边界（提交）
├── manifest.csv          # 每次下载后的来源与哈希记录（提交）
├── single/               # 12 张 1024×1024 单图演示样本（忽略）
└── batch/                # 192 张 512×512 批量流程样本（忽略）
```

总数为 204 张 JPEG。图片本体由 `.gitignore` 排除，避免把外部影像、数据或大文件推送至仓库。

## 3. 数据来源与技术方案

下载器使用 Python 标准库请求 USGS National Map 的 `USGSImageryOnly` ArcGIS 导出接口。USGS 的服务描述表明，它提供高分辨率正射影像，覆盖美国本土时主要来源于 NAIP，典型分辨率约 6 英寸至 1 米；服务归属为 `USDA, USGS The National Map: Orthoimagery`。

12 个选点覆盖海岸城市、密集城区、郊区、沙漠城市、农田、森林和湿地。每个选点生成：

- 1 张更大范围的 1024×1024 单图样本；
- 4×4 网格的 16 张 512×512 批量样本。

下载器验证 JPEG 头、进行有限重试，并为每张成功图片记录 WGS84 边界框、来源服务、归属、SHA-256、字节数、下载时间和状态。

## 4. 严格能力边界

- 这是一套**工程输入样本**，不是 RSVQA-HR 的原始、训练、验证或带标签测试数据。
- `visual_theme_not_ground_truth` 只是选点的人工描述，不能被当作模型真值、问题答案或自动评测标签。
- 当前运行时仍是 `mock_demo`；任何页面结果都不是 research ViLT predicted-soft 结果。
- 未来接入真实模型后，这些图片最多用于 API/批量流程 smoke，不能用于计算 OA、AA、F1 或论文比较结论。
- 影像仅保存在本机；公开再分发前必须单独复核来源条款和归属。

## 5. 验收标准

1. 下载命令无须 API key、GPU 或重型依赖。
2. 完整运行后生成 12 个 `single/*.jpg`、192 个 `batch/*.jpg` 和 `manifest.csv`。
3. 每个成功条目均通过 JPEG 头检查，并拥有 SHA-256 与字节数。
4. Git 状态不包含任何 `single/` 或 `batch/` 图片。
5. 文档清楚说明其工程用途与不可用于模型精度评测的边界。
