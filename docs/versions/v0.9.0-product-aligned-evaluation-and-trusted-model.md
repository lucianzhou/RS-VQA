# v0.9.0 产品对齐评测与可信研究模型体验

状态：验收中

日期：2026-07-27

论文题目固定为《跨模态特征融合机制及微调策略研究与应用》。

## 本版目标

本版不训练模型，也不宣称 checkpoint 改善。目标是把研究侧固定的 predicted-soft 模型、
产品对齐评测和能力证据接入独立应用，证明工程推理链不改变模型行为，并把真实短板透明展示给用户。

主流程保持：

```text
上传图像 -> 自然中文或英文提问 -> 固定发布推理 -> 可信答案展示
         -> 可选 RS-Bot 解释/检索/汇总 -> 可追溯历史与报告
```

## 已实现

- 模型、评测 release schema、固定 ID 与哈希契约。
- Real Runtime 对预期 release ID 和 manifest SHA-256 的启动固定；缺失时 fail closed。
- checkpoint、55 类词表、runtime wheel、预处理器树的逐制品校验。
- 8/512/3072 三集合隔离、路径越界防护、只读与 inventory 校验。
- diagnostic-test 显式 sealed gate 和不持久化逐样本预测的聚合 runner。
- corrected 55 类 OA/AA、Count、yes/no 和 Area 规范化评分。
- 原始问题、canonical question、实际模型输入问题和 normalizer 版本的持久化。
- 研究答案、Mock、Gemini、Qwen3 和 RS-Bot 的独立来源标识。
- confidence、margin、top-k、题型概率、哈希、review policy 和能力边界的可展开 UI。
- Count 非零/密集低估提示；默认不启用自动拒答。
- RAG 失败索引可在原文档 ID 上幂等恢复，BGE/Milvus 引用链已验证。
- 并行项目刷新不会把刚创建并正在工作的活动会话错误切走。

## 研究事实与能力边界

- 正式 full test OA/AA：`0.8401412/0.8390032`。
- 正式 full test_phili OA/AA：`0.8031558/0.7975786`。
- 不声称 SOTA；predicted-soft 相对 none 的配对置信区间包含 0。
- 模型是 RSVQA-HR grouped 55-answer closed-set classifier，不是开放式视觉助手。
- diagnostic 显示非零/密集 Count、长尾答案和 Philadelphia 地域迁移仍是模型短板。
- confidence/margin 不保证答案正确，全局自动拒答默认关闭。
