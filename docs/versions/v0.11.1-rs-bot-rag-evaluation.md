# RS-VQA v0.11.1 技术方案与功能介绍：RS-Bot 与 RAG 冻结评测

> 日期：2026-07-30
>
> 分支：`feature/trusted-application-p1`
>
> 研究模型、checkpoint 和发布协议未修改。

## 1. 目标

此前 RS-Bot 只有规划循环单元测试，RAG 只有 3 条标题命中查询，无法支持“Agent 可靠”
或“知识检索有效”的工程结论。本版本建立两层互不混淆的评测：

- RS-Bot 离线契约评测：证明工具循环能够强制执行白名单、上下文绑定、数字忠实、引用和写操作拒绝；
- RAG 真实检索评测：在当前 BGE-small-zh-v1.5 与 Milvus v2 上实际索引、检索并清理受控文档。

离线脚本模型不衡量 Gemini 自主选工具的质量，不能替代付费 live benchmark。

## 2. RS-Bot 50 条冻结任务

固定清单：

| 类别 | 数量 |
| --- | ---: |
| 确定性查询 | 15 |
| 多工具任务 | 10 |
| 知识引用 | 10 |
| 无答案拒答 | 5 |
| 提示注入与越权 | 5 |
| 写操作确认 | 5 |

评测直接运行真实 `RsBotPlanner`，脚本化模型只提供可重复的模型 turn。工具调用、资源 ID
重绑定、工具白名单、输出围栏、停止条件和拒绝状态均由生产代码执行，不在测试中绕过。

结果：

```text
tasks=50
passed=50
overall_success_rate=1.000
numeric_fidelity=26/26
citation_fidelity=11/11
unauthorized_write_executions=0
cross_context_leaks=0
redundant_calls=0
```

引用案例要求回答同时写出文档标题和分块。RS-Bot 系统提示同步升级为
`rs-bot/1.1.0`：空引用或无关证据必须拒答，知识文本不能替代当前图像 VQA。

## 3. RAG 40 条真实检索

固定清单包含：

| 类别 | 数量 |
| --- | ---: |
| 可回答知识查询 | 25 |
| 无答案查询 | 5 |
| 提示注入文档查询 | 5 |
| 双向租户隔离查询 | 5 |

评测使用独立 `rsvqa-knowledge-eval-v2` index version，创建 7 份非敏感临时文档。
所有临时文档均为 PRIVATE，分别绑定两个固定评测 owner；运行结束后通过 tenant-bound delete
清理，并再次查询确认残留 citation 数为 0。

第一轮统一阈值 `0.55` 的真实结果为 Recall@3 `0.50`、无答案准确率 `1.00`，说明阈值过高。
零阈值诊断显示相关证据最低分约 `0.428`，无答案查询最高分约 `0.334`。因此统一阈值调整为
`0.40`，保留约 `0.066` 的观测间隔，而不是按题设置阈值。

为减少 top-3 中明显弱于最佳结果的引用，服务增加 `best_score - 0.08` 相对分差过滤，同时不降低
绝对阈值。最终真实结果：

```text
case_count=40
overall_success_rate=1.000
recall_at_3=1.000
mrr=0.9056
citation_precision=0.5455
citation_support_rate=1.000
no_answer_accuracy=1.000
injection_retrieval_rate=1.000
cross_tenant_leaks=0
cleanup_failures=0
```

`injection_retrieval_rate` 只表示恶意文本能被检出并交给围栏处理，不表示模型执行其中指令；
非执行性由 RS-Bot 离线安全任务证明。

## 4. 可复现命令

```bash
cd apps/gateway
mvn -Dtest=RsBotOfflineEvaluationTest test

cd ../..
docker exec rs-vqa-knowledge-service-1 \
  python scripts/evaluate_retrieval_v2.py
```

知识服务自动测试：

```bash
cd services/knowledge-service
../model-service/.venv/bin/python -m pytest -q
```

当前为 15 passed。

## 5. 边界与后续

- 50 条离线任务证明工程控制面，不证明 Gemini live 规划成功率；
- 真实 Gemini 50 条批量评测会产生费用，必须取得用户预算确认后单独运行；
- 当前 RAG 文档规模仍小，最终指标只能描述该冻结受控集合；
- citation precision `0.5455` 表明 top-3 仍可能包含辅助候选，Agent 必须按标题、分块和内容逐项引用；
- 本阶段没有训练研究模型、改写研究预测或访问受限 gold。
