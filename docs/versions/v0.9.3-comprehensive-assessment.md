## 冻结判断

建议产品定位：

> 面向遥感/GIS 教学、科研复核和受控影像初筛的多模型遥感问答与批量复核工作台。

当前成熟度：

> 高质量单机论文演示与研究复核工作台，尚不是经真实业务验证的生产遥感分析系统。

研究模型关键边界：

- full test OA/AA=`0.8401412/0.8390032`；
- test_phili OA/AA=`0.8031558/0.7975786`；
- 512 条答辩集 OA/AA=`0.8515625/0.8515625`；
- Count 非零=`8/47=17.02%`；
- 3592/3592 工程 runtime 与冻结预测一致，差表现不能归因于发布链错误。

## P0 发现

1. RAG 写入 owner 但检索只按 index_version 过滤，存在跨用户片段返回风险。
2. Session Cookie API 对全部 `/api/**` 忽略 CSRF。
3. `/mcp` 匿名开放；未认证 `initialize` 实测返回 HTTP 200。
4. 批任务依赖进程内 `@Async`，没有 lease 和启动恢复。

这些问题不影响当前本机单用户论文演示的基本 VQA，但在修复前不能描述为安全的多用户或公网系统。
