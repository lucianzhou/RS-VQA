# v0.9.2 批量结果影像现场复核

## 本版目标

批量 VQA 任务完成后，结果列表不再只显示文件名。每条结果同时展示对应遥感影像缩略图，
用户可直接点击，在当前页面查看原图并与问题、回答和置信度进行人工对照。

## 功能与技术方案

- 批量结果行增加固定 `48 x 48 px` 缩略图，不挤压文件名、问题、答案和置信度。
- 悬停或键盘聚焦时显示放大提示，点击后复用单图问答已有的 `ImageLightbox`。
- 大图弹层显示原文件名和该结果对应的问题，支持关闭、Escape 返回和下载原图。
- 缩略图使用延迟加载；任务历史重新打开后仍可查看，不依赖浏览器中的临时上传 URL。
- 新增受登录保护的批任务影像读取接口：
  `GET /api/v1/batch-jobs/{jobId}/items/{itemId}/image`。
- 服务端先校验批任务属于当前用户，再校验结果项属于该任务，随后以内联图片响应返回，
  不向前端暴露存储路径。

## 边界

- 缩略图用于人工现场复核，不改变模型输入、预测结果或评测指标。
- 同一图像对应多个问题时，每条结果均保留缩略图，确保问题与结果逐项对应。
- 图像仍保存在本地受控存储和 Docker 数据卷中，不进入 Git。
