# v0.3.0 API、数据与运行时契约

> 状态：已实现并按 2026-07-24 运行结果核验  
> 浏览器业务 API 前缀：`/api/v1`

## 业务 API

### 身份、项目与会话

| 方法与路径 | 作用 |
| --- | --- |
| `POST /auth/demo` | 建立受控本地演示 Session |
| `POST /auth/register` | 本地注册，BCrypt 12 哈希 |
| `POST /auth/login` | 本地登录 |
| `POST /auth/logout` | 退出并失效 Session |
| `GET /me` | 当前身份与角色 |
| `GET /projects` | 当前用户项目及会话摘要 |
| `POST /projects` | 新建项目 |
| `POST /projects/{projectId}/conversations` | 新建一图一会话的分析 |
| `GET /conversations/{conversationId}` | 图像、消息及历史调用 |
| `POST /conversations/{conversationId}/image` | 上传或更换图像 |
| `DELETE /conversations/{conversationId}/image` | 移除图像上下文 |
| `GET /conversations/{conversationId}/image/content` | 权限校验后的图像内容 |
| `GET /conversations/{conversationId}/report` | 导出 Markdown 会话报告 |
| `POST /conversations/{conversationId}/questions` | 发起并持久化 VQA |

`POST /vqa/answers` 作为 v0.1 迁移兼容端点暂时保留。

### 模型、Agent、MCP 与系统

| 方法与路径 | 作用 |
| --- | --- |
| `GET /providers` | 研究模型/外部 VLM 能力和配置状态 |
| `GET /system/status` | PostgreSQL、Redis、模型、RAG、Agent、MCP 摘要 |
| `GET /agent/tools` | 六个只读工具 + `single_image_vqa` 受控工具 Schema |
| `POST /agent/runs` | 同步可信单 Agent 运行 |
| `POST /agent/runs/stream` | SSE 阶段流，浏览器可取消 |
| `GET /mcp/client/status` | 可选 Spring AI MCP Client 状态 |
| `GET /mcp/client/tools` | 发现远端白名单工具 |
| `POST /mcp/client/tools/{toolName}` | 调用远端白名单工具 |
| `/mcp` | stateless、同步、只读 MCP Server |

未配置 MCP Client 时状态端点返回 `configured=false`，发现或调用不会伪造结果。Server 实际发布六个工具：`current_model_release`、`supported_question_types`、`system_health`、`conversation_history`、`batch_job_status`、`search_knowledge`。

## Python 模型运行时

模型服务只负责运行时，不保存用户、会话和业务事实。

| 方法与路径 | 作用 |
| --- | --- |
| `GET /health` | 进程存活 |
| `GET /ready` | 当前 runtime 是否可推理 |
| `GET /models/current` | release、模式、协议与边界 |
| `POST /v1/vqa` | 单图推理 |
| `POST /v1/vqa/batch` | 有界批量推理 |
| `POST /v1/predict` | v0.1 迁移别名 |

请求只包含图像、原始问题和可选 `model_release_id`。服务绝不接受 `question_type_id`、gold label、split 或 mask。

核心响应：

```json
{
  "request_id": "uuid",
  "status": "answered",
  "supported": true,
  "prediction": "yes",
  "answer": "yes",
  "confidence": 0.79,
  "margin": 0.58,
  "top_k": [{"answer": "yes", "probability": 0.79}],
  "canonical_question": "Is there a road?",
  "question_type": "presence",
  "predicted_question_type": "presence",
  "question_type_probabilities": {"presence": 1.0},
  "prediction_origin": "mock_demo",
  "model_release_id": "mock-demo-not-a-research-release",
  "task_scope": "rsvqa_hr_grouped_answer_closed_set",
  "limitations": ["Mock output must not be used as thesis evidence."],
  "capability_notice": "当前为 Mock 演示输出……",
  "input_sha256": "sha256",
  "latency_ms": 3,
  "runtime_mode": "mock"
}
```

`RSVQA_MOCK_LATENCY_MS` 仅用于自动化验证取消和进度，范围为 0–5000 ms，默认 0；它不是业务配置。

## 知识检索运行时

`services/knowledge-service` 提供 `/health`、`/ready`、`POST /v1/documents`、`DELETE /v1/documents/{id}` 与 `POST /v1/search`。BGE 模型、Milvus URI、collection 与索引版本均可配置。业务 API 对外使用 camelCase；网关负责将 Python snake_case 转换为公共契约，避免 DTO 细节泄漏。

## 错误协议

业务错误统一为：

```json
{
  "code": "PROVIDER_NOT_CONFIGURED",
  "message": "MCP Client 未配置。",
  "requestId": "uuid",
  "timestamp": "2026-07-24T00:00:00Z",
  "details": {},
  "retryable": false
}
```

覆盖文件校验、模型不可用、Provider 未配置、RAG 不可用、MCP 工具失败、权限不足与通用内部错误。前端不会收到 Java/Python traceback。

## 数据模型

Flyway V1–V4 已创建并迁移：

`User`、`Project`、`Conversation`、`Message`、`ImageAsset`、`ModelRelease`、`ModelInvocation`、`AgentRun`、`ToolInvocation`、`BatchJob`、`BatchItem`、`KnowledgeDocument`、`KnowledgeChunk`、`AuditEvent`。

- UUID 主键；关键实体含 `created_at`、`updated_at`。
- 消息记录 `source_type`，历史调用固定当时 release ID。
- 图像保存在受控文件存储；PostgreSQL 只保存内部路径、SHA-256、MIME、尺寸和大小。
- PostgreSQL 是业务事实源；Redis 只保存短期任务快照和协调状态。
- checkpoint、模型、原图二进制和凭据不进入数据库。
