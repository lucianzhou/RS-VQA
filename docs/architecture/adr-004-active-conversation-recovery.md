# ADR-004：活动会话恢复与项目树一致性

## 状态

已接受，v0.4.0

## 背景

工作区是单页应用，刷新后 React 内存状态会丢失；如果直接从项目列表的第一个会话恢复，
用户可能看到错误的项目或错误的历史。新建对话时，项目树刷新又是异步的，过早校验活动会话
会把刚创建的会话误判为不存在。

## 决策

- 在当前浏览器 `sessionStorage` 保存 `activeProjectId` 和 `activeConversationId`，仅作为导航恢复
  信息，不保存图像、问题答案或凭据。
- 项目列表加载完成后验证活动会话仍属于当前用户；无效时回退到稳定排序的第一个可访问会话。
- 创建项目/对话时，先等待项目树刷新完成，再切换活动会话并写入恢复状态。
- 退出登录时清理恢复状态。

## 结果

刷新恢复不依赖 URL 泄露业务 ID，也不会跨浏览器持久化演示上下文；归档或权限变化后可安全回退。
Playwright 多轮 VQA 刷新用例和移动端导航用例已通过。
