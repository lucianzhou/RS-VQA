> 状态：实施中

## 核心来源契约

| 来源 | 允许内容 | 禁止内容 |
| --- | --- | --- |
| `research_vilt_predicted_soft` | 已验证 RSVQA-HR 闭集答案、置信度、margin、top-k、题型预测与 release provenance | 开放式描述、人工题型、oracle/routed |
| `external_vlm_assist` | Gemini 开放式视觉辅助结果 | 伪装为论文模型结果 |
| `mock_demo` | 确定性工程演示输出 | 论文指标、真实 checkpoint 声明 |
| `agent_synthesis` | 基于工具事实和引用的解释、计划与报告草稿 | 改写原始预测、编造统计 |

## 工作区命令

项目和对话命令使用可恢复归档，不以删除作为默认动作：

```text
PATCH /api/v1/projects/{id}                  rename
POST  /api/v1/projects/{id}/archive
POST  /api/v1/projects/{id}/restore
PATCH /api/v1/conversations/{id}             rename or move
POST  /api/v1/conversations/{id}/archive
POST  /api/v1/conversations/{id}/restore
GET   /api/v1/archive
```

所有命令校验当前用户所有权并写入审计。归档项目时其对话保留原状态；恢复项目不隐式恢复已单独归档的对话。

## 图片预览

Lightbox 只读取现有受控内容 URL，不建立新的公开文件端点。批量上传前的浏览器预览使用 Object URL，并在文件移除、替换和组件卸载时释放。

## Agent 事实工具

v0.4 工具分为三类：

1. 只读事实：release、能力、健康、会话、项目、批量统计、置信度、拒答、失败、知识和审计。
2. 受控推理：单图 VQA、批量计划、报告事实包。
3. 有副作用操作：创建任务、重试、保存报告、归档。必须产生待确认动作，不允许模型直接执行。

工具返回结构化 JSON；展示文案不是事实源。

## Gemini Provider

Provider 配置只存在于服务端：

```text
RSVQA_EXTERNAL_PROVIDER=google-genai|openai-compatible|disabled
RSVQA_EXTERNAL_BASE_URL=<optional>
RSVQA_EXTERNAL_MODEL=<model-id>
RSVQA_EXTERNAL_API_KEY=<secret>
```

API 响应只能返回配置状态、模型 ID、能力、限制和费用元数据，不返回 key 或原始认证错误。未配置时返回 `PROVIDER_NOT_CONFIGURED`，不能自动切换到 Mock 或研究模型。

## 报告事实分区

报告必须明确分隔：

1. 原始模型调用事实
2. Java/SQL 确定性统计
3. RAG 引用
4. Agent/Gemini 解释
5. 人工确认状态

每个报告版本固定输入范围、模型 release、Provider/model、生成时间和 request ID。
