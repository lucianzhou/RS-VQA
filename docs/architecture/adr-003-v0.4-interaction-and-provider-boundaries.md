# ADR-003：v0.4 交互系统与 Gemini Provider 边界

> 状态：已接受
> 日期：2026-07-24
> 适用版本：v0.4.0

## 背景

v0.3.0 已完成 React 工作台、Spring AI 工具边界、Mock/Real 模型协议、批量任务和 BGE/Milvus 检索，但仍存在三类缺口：

1. 项目树、归档、账户菜单、模型选择器和图片预览尚未形成完整工作流。
2. 页面缺少统一的空间动效，侧栏收起后的布局重排不可靠。
3. 外部通用视觉模型尚未接入，可信 Agent 只覆盖少量只读工具，不能完成项目级统计与报告。

## 决策

### 交互原语

- 使用 React Portal 与经过测试的无障碍原语承载 popover、menu 和 dialog。
- 使用 Motion for React 处理需要可中断、可反向或共享空间关系的动画。
- 高频导航保持即时；只为状态反馈、空间连续性和避免突变添加动画。
- 所有动效遵守 `prefers-reduced-motion`，并使用统一 duration/easing token。

### 页面宽度

- 应用壳始终占满视口。
- 侧栏是可折叠导航区域；折叠只改变导航占用，不限制主画布宽度。
- 对话正文保持窄阅读列，批量任务、报告和审计使用更宽工作区。

### Gemini

- `Spring AI` 继续作为唯一正式 Agent 编排层。
- Gemini 通过 `ExternalVisionProvider` 抽象接入；首选 Spring AI Google GenAI，保留 OpenAI-compatible 配置 seam。
- `pi-agent-core` 只作为 `gongkao` 项目的工程参考，不进入 RS-VQA 正式运行链。
- API key 仅由服务端 secret 注入；浏览器登录与 Google AI Pro 会员不构成 API 授权。

### 输出来源

所有输出必须固定为以下来源之一：

- `research_vilt_predicted_soft`
- `external_vlm_assist`
- `mock_demo`
- `agent_synthesis`

Agent 或 Gemini 不得覆盖研究模型原始结果。确定性统计由 Java/SQL 生成，LLM 只解释结构化事实。

## 后果

- 前端新增少量专用依赖，但避免手工实现易出错的焦点管理和 Portal。
- Gemini 未配置时系统仍完整运行，并明确显示 `UNCONFIGURED`。
- 真实研究模型仍由研究仓库不可变发布物控制；v0.4 不导入训练代码。
